# 内置浏览器（browser-use）

IllusionAgent 内置浏览器让你（和 agent）直接打开、浏览、操作和验证网页——
为 agent 与用户提供完整的网页浏览、操作与验证能力。右栏「浏览器」区块是入口，浏览器本体在
右侧**文件预览卡片**的「浏览器」标签页中打开，与文件/Diff 预览并列。

## 快速开始

1. 展开右栏，找到「浏览器」区块，点击「打开浏览器」。
2. 浏览器在右侧预览卡片中打开（与文件预览并列为一个标签页）。
3. 在顶部地址栏输入网址回车即可浏览；也可以直接在聊天里说
   「帮我打开 example.com 并截个图」，agent 会代为操作。

前置条件（仅 Web/终端模式）：

- Playwright 是 illusion-agent 的必需依赖（安装包自带），无需额外安装。
- Chromium 内核：已有系统 Chrome/Edge 时自动兜底使用，无需下载；
  两者都没有时执行一次 `illusion browser setup`（下载约 130MB）。

桌面版使用应用自带内核，无需任何安装。

## 界面布局

预览卡片中的浏览器标签页自上而下分为两部分：

**工具栏**

- 后退 / 前进 / 刷新按钮与地址栏（回车导航；裸域名自动补 `https://`，
  本机地址自动补 `http://`）；
- 自由尺寸切换：开启后出现视口工具栏——宽 × 高输入、适应窗口 / 50–200%
  缩放，画面四边四角可拖拽调整（拖拽时缩放自动冻结为当前百分比）；
- 元素拾取：开启后点击页面元素即可把它作为附件发给 agent；
- 「⋯」菜单：在系统默认浏览器打开 / 打开页面调试工具；
- agent 操作指示（agent 正在操作页面时点亮）。

**画面区**

- 桌面模式：实时画面，可直接点击、滚动、键入；
- Web 模式：截图画面，点击/滚轮/键盘会转发到真实页面——
  「点击画面聚焦 → 直接键入 → 回车提交」，底部有聚焦状态提示。

## 两种运行模式

| 模式 | 适用端 | 画面 | 交互 |
|------|--------|------|------|
| `desktop`（内置浏览器） | 桌面版 | Electron `<webview>` 实时画面 | 原生直接交互 |
| `managed`（托管浏览器） | Web / 终端 | Playwright 托管 Chromium 的截图流 | 点击/滚动/键盘转发 |

托管内核解析顺序：Playwright Chromium → 系统 Chrome → 系统 Edge
（可在设置中固定，见下文配置）。每个后端标签页是预览卡片顶栏的一个
标签页：点击切换、悬浮 X 关闭、「+」新建（可输入网址直达）、
垃圾桶关闭其他、减号收起卡片（标签页与画面保活）。桌面版的内置
浏览器主题跟随应用深浅色设置。

## Agent 如何使用浏览器

启用 browser-use 插件后，agent 获得两个技能与一组 `browser_*` 工具：

- **`browser-use:control-browser`**：浏览/操作/验证网页的主工作流
  （导航 → ARIA 快照读页 → 按 ref 点击输入 → 截图验证）；
- **`browser-use:web-gui-tester`**：GUI 黑盒测试方法论（测试计划 →
  执行 → 双重验证 → 报告）。

工具清单：`browser_navigate`、`browser_snapshot`、`browser_screenshot`、
`browser_click`、`browser_type`、`browser_press_key`、`browser_scroll`、
`browser_evaluate`、`browser_tabs`、`browser_resize`、`browser_wait`、
`browser_close`。

要点：

- agent 读页面的首选是 `browser_snapshot`（ARIA 树 + `[ref=eN]` 引用），
  截图只在需要视觉验证时使用；
- 页面内容被视为不可信数据，仅用于定位元素；
- 仅允许 `http:` / `https:` / `about:blank`；
- agent 开始操作时，浏览器画面自动弹出并在工具栏显示操作指示；
- 截图会同时出现在聊天工具卡片与浏览器画面中。

## 配置

浏览器配置位于 `~/.illusion/settings.json` 的 `browser` 节，
也可在 **设置 → 扩展能力** 中图形化修改（按运行端分支显示：
Web/终端端展示下列托管配置，桌面端展示浏览器数据管理）：

```jsonc
{
  "browser": {
    // 托管内核：auto（默认，按解析链自动选择）/ chromium / chrome / msedge
    "kernel": "auto",
    // 托管模式是否无头运行（桌面版恒为可视 webview，不受此项影响）
    "headless": true,
    // 默认视口尺寸（320-3840 × 320-2160）
    "viewport_width": 1280,
    "viewport_height": 720,
    // 代理：auto（默认，自动探测 Windows 系统代理与 HTTP(S)_PROXY）/
    // off / 显式代理 URL（如 "http://127.0.0.1:7890"）
    "proxy": "auto"
  }
}
```

## 插件与开关

浏览器能力由内置 **browser-use** 插件承载（默认启用）：

- **设置 → 扩展能力**：Switch 开关热切换（当前会话即时生效，无需重启）；
- 右栏插件列表：同名开关；
- 斜杠命令：`/plugin enable browser-use`、`/plugin disable browser-use`。

禁用后 12 个 `browser_*` 工具与两个技能立即注销，重新启用即时恢复。
插件 seed 于 `~/.illusion/plugins/browser-use/`，随版本自动更新。

## 浏览器数据管理

桌面版在 **设置 → 扩展能力** 中提供两项数据管理（Web/终端模式不展示，
托管浏览器的数据随进程结束丢弃）：

- **清除全部浏览器数据**：清除 Cookie、缓存与站点数据，退出全部网站登录；
- **清除浏览器缓存**：仅清除缓存文件，保留登录状态与站点数据。

## 常见问题

**浏览器打开后是空白页？**
在地址栏输入网址回车即可；空白引导层会提示这一动线。也可以直接让
agent 代为打开网页。

**点击画面没有反应？**
Web 模式的点击会先转发到真实页面再回推新截图，约数百毫秒延迟；
确认浏览器处于运行状态（右栏区块显示当前页面）。

**导航被拒绝？**
仅允许 `http:` / `https:` / `about:blank`；`file:`、`data:`、
`javascript:` 协议一律拒绝（安全约束）。

**桌面版和 Web 版有什么区别？**
桌面版使用 Electron 内置内核的实时画面（原生交互，最流畅）；
Web 版使用托管 Chromium 的截图流（点击/键盘转发，近似操作）。
两者由 agent 驱动时行为完全一致。

**GitHub 等外网站点打不开？**
托管（无头）Chromium 不会自动继承 Windows 系统代理。`browser.proxy`
默认为 `auto`：自动探测系统代理（Clash/v2rayN 等）与 `HTTP(S)_PROXY`
环境变量并显式接入；也可在 设置 → 插件 → browser-use 中填显式地址，
或设为 `off` 禁用。若代理软件未运行或节点不可用，外网站点仍会失败——
此时导航失败信息会显示在浏览器画面区顶部。桌面版 webview 原生走系统
代理，无此问题。

**端口/安全？**
桌面版的浏览器控制服务器只监听 `127.0.0.1` 且每次启动随机 token；
托管浏览器运行在后端进程内，不额外开放端口。
